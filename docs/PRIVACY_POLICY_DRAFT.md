## 一、功能与数据处理

您输入 RTSP 地址或发起 ONVIF 局域网搜索时，本应用连接您选择的地址或所在网络中发现的摄像机；您输入的 RTSP 地址也可以指向远端服务。连接地址可能包含用户名、密码或令牌；您输入的 ONVIF 账号密码也可能发送给摄像机用于认证。账号与密码均留空并经您确认搜索时，应用可能向发现的设备尝试默认账号 `admin/admin`。普通 RTSP 与 ONVIF HTTP 连接可能不加密，请在可信网络中使用，并优先选择设备支持的加密协议。

本应用在您点击连接时保存上次尝试的 RTSP 地址，即使连接失败也会保存；另保存最近最多 10 条成功连接的地址。这些地址由 Android Keystore 密钥进行 AES-GCM 加密，系统备份和设备迁移备份已关闭。您可以在“历史记录”中清除这些地址；清除操作也移除上次尝试的地址。历史页面只展示协议、主机和端口。ONVIF 搜索结果、设备型号、序列号和服务地址会在当前页面会话中显示；原始响应仅在调试包中显示。[用最终正式包确认 SDK 是否另行持久化或上传。]

您主动截图、录像或导入水印图片时，新文件保存在应用内部存储空间。视频画面可能包含可识别的人物或场所。旧版本已保存到外部应用专属目录的截图与录像仍会显示，供您查看或删除；在旧版 Android 设备上，该旧目录可能被拥有存储读取权限的其他应用访问。您点击“打开”时，系统会把所选文件的临时只读访问权限授予所选查看应用。水印文字保存在本机偏好设置中；水印图片会保存在应用内部文件目录，可在水印设置中删除或替换。

当前 app 源码未见广告或统计 SDK 接入，也未见开发者云端上传流程；**这不构成对内置 RoboYiPlayer/GStreamer AAR 实际网络行为的结论**。上架主体须检查最终二进制与网络流量，再完成下节的第三方清单及商店 Data safety 申报。
