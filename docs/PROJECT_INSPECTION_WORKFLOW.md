# 项目检查录像

左侧“项目”打开横屏管理页：中部左侧项目摘要约占屏幕宽度三分之一，右侧当前项目下全部任务约占三分之二；新增、修改、确认使用和目录操作统一放在底部。点击列表只浏览；“使用所选”才切换当前录像项目和任务。“修改”查看并编辑全部字段。
底部精简为单排六个入口：返回、新建、修改当前项目/任务、OSD 规则、更多、使用所选。“新建”菜单选择项目或任务；“修改”跟随最后点选的左/右条目变化，重复点击同一项目不会清除已选任务。不使用项目、取消任务选择、目录授权和 XML 导出收进“更多”。
项目包含名称、编号、委托公司、执行单位；项目下的任务包含名称、编号、地点、执行人。
项目、任务、缺陷分别允许新增 10、20、10 个自定义字段。字段名称永久保存为全局模板，新建记录自动带出，字段值分别填写。
录像开始后，本次项目、任务和水印规则被冻结；结束后可编辑，历史 XML 不受影响。

## 水印

项目页“水印规则”或播放页“水印 → 项目 / 任务 / 缺陷 / 时间规则”提供逐字段配置：显示开关、X/Y（0–100）、字号（8–96）、文字颜色、背景颜色、OSD 透明度（0–100%）、时间格式。
文字和背景色按黑、白、红、橙、黄、绿、蓝、靛、紫九个色系排列，每行从浅到深三色，共 27 色；背景另可选择透明。OSD 透明度 0% 为不透明、100% 为完全透明，同时作用于文字和背景；透明背景不影响文字。旧规则默认不透明，原有颜色保留。
OSD 页左侧选择字段、中间显示整套规则、右侧编辑属性；使用与录像相同的 SDK 渲染。可拖动任意 OSD，红框标记选中项。所有 OSD 滑条（X/Y、字号、透明度、时长和模拟进度）两侧提供 − / + 按钮，每次微调 1 个单位，到达上下限时禁用相应按钮；保留拖动和点击数值精确输入。常规规则支持全量布局与 60 秒时段模拟。未填写字段以占位内容预览，实际录像仍忽略空值。
“应用到全部”可勾选字号、文字颜色、背景颜色、透明度、显示、位置和时段，默认不复制位置；复制位置会提示重叠。项目/任务/时间与缺陷分别批量应用，不相互影响。

时间范围支持全程、前 N 秒、第 N 秒至结束前 M 秒、最后 M 秒。秒数使用有效录像时间，暂停不计时。
为在实时录像中确定最后 M 秒，点击停止后倒计时补录，取所有有效片尾规则的最大 M。进入片尾后不能暂停，完成后封装视频。
断流、安全停止等异常停止不能保证完整片尾时长，XML 标记 `safety-stopped`。

## 目录和 XML

Android 10 及以上首次录像需要通过系统文件夹选择器授权内部存储的 `DCIM` 或 `DCIM/RoboYiPlayer`，用于将 XML 与媒体并列保存。
媒体通过 MediaStore 发布，XML 通过持久化目录授权写入；不申请所有文件访问权限。
根目录位于公共存储，不是应用专属目录。旧 `DCIM/RtspPlayer` 中的文件保留并兼容查看，不自动迁移；若此前仅授权旧文件夹，需要重新授权新目录，已有 DCIM 授权可直接复用。

```text
DCIM/RoboYiPlayer/
  项目名称/
    项目名称_项目编号_yyyyMMddHHmmss.mp4
    项目名称_项目编号_yyyyMMddHHmmss.xml
    项目名称_项目编号_yyyyMMddHHmmss/
      snapshot_时间戳.jpg
  yyyyMMddHHmmss/                 # 未选择项目的录像
    yyyyMMddHHmmss.mp4
    yyyyMMddHHmmss.xml
    yyyyMMddHHmmss/
      snapshot_时间戳.jpg
  pictures/yyyyMMddHHmmss/        # 非录像期间截图
    snapshot_时间戳.jpg
```

非法文件名字符转换为下划线，同秒同名录像自动加序号。XML 中的相对路径均以 `DCIM/RoboYiPlayer` 为基准，结构是 `recording/project/task/video` 和 `recording/project/task/screenshots/screenshot/defect`。
项目和任务未选择时仍输出对应节点，并注明 `selected="false"`。水印配置保存于 `watermarkRules`。
录像启动、截图/缺陷保存、录像结束均更新 XML；写入失败保留内部备份，可在项目页“重新导出 XML”。

## 缺陷和文件查看

选定项目开始录像后，每次截图会弹出缺陷表单，可填写名称、位置、长度、详情及自定义字段，也可跳过。
缺陷录入左侧预览本次截图，右侧填写全部信息，底部保存/跳过。缺陷 OSD 只有样式、位置和截图后显示时长，不提供片头/片中/片尾规则。旧的缺陷录像时段设置自动忽略，也不会触发片尾补录。
保存时配置本次缺陷显示秒数（0 表示不在视频中显示）。从保存起按单调时钟独立倒计时，不受录像暂停影响；显示结束后将带缺陷文字的图片替换原截图；录像先结束时提前完成图片替换。默认时长在缺陷 OSD 页保存，每次截图可单独调整。
替换基于该次截图的原始帧，不抓取后来的帧。原始帧保留在应用私有目录，避免覆盖失败丢失。
文件页按项目、任务两级分组，各级标题支持整组全选/取消选择。

## 本次验证

Debug 构建和设备安装；隔离测试目录中的模板上限、持久化、项目任务选择、历史快照、XML 转义和层级、路径和水印时段边界、27 色与透明背景及透明度持久化校验；真机打开项目管理页及 OSD 设置。
完整录像、片尾补录和截图缺陷联动需在首次文件夹授权后使用实际视频进行验收。
